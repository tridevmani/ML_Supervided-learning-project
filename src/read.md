# Supervised Learning Project

This project implements multiple supervised learning algorithms on the Breast Cancer dataset.

## Algorithms Used
- Logistic Regression
- KNN
- Decision Tree
- Random Forest
- SVM
- Naive Bayes
- Gradient Boosting

## Features
- Data Visualization
- Model Comparison
- Feature Importance
- Cross Validation
- Hyperparameter Tuning
- Model Saving

## How to Run

```bash
pip install -r requirements.txt
python src/main.py
